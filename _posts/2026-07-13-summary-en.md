## [GPT-5.6 Solves 50-Year Graph Conjecture in Under an Hour](https://www.qbitai.com/2026/07/447873.html) ⭐️ 10.0/10

OpenAI's GPT-5.6 Sol Ultra model proved the cycle double cover conjecture, a 50-year-old graph theory problem, in less than one hour by coordinating 64 sub-agents. OpenAI also released the complete 700-character prompt used for this achievement. This marks the first time an AI system has autonomously solved a long-standing open mathematical conjecture, demonstrating advanced reasoning and multi-agent collaboration. It could revolutionize how mathematical research is conducted and set a new benchmark for AI's role in scientific discovery. The model transformed the problem into edge labeling over finite fields and solved linear equations, generating a 3-page PDF proof. The released prompt does not specify fixed steps but defines acceptance criteria, definitions, boundary conditions, and failure cases, while requiring dynamic sub-agent assignment and independent review.

telegram · zaihuapd · Jul 12, 03:49

**Background**: The cycle double cover conjecture, posed independently by Szekeres (1973) and Seymour (1979), asks whether every bridgeless graph has a collection of cycles covering each edge exactly twice. A bridgeless graph is one where no single edge, when removed, disconnects the graph. This conjecture is a fundamental problem in graph theory and has resisted proof for five decades.

## [World's First Invasive BCI Medical Device Approved in China](https://t.me/zaihuapd/42515) ⭐️ 10.0/10

China's National Medical Products Administration (NMPA) approved the world's first invasive brain-computer interface medical device, the implantable BCI hand function compensation system developed by Borei Kang Medical Technology (Shanghai) Co., Ltd., bringing it into clinical use for tetraplegic patients. This approval marks a landmark milestone in neurotechnology, offering a new rehabilitation option for patients with cervical spinal cord injury who have lost hand function. It could accelerate the development and adoption of invasive BCI devices in medical treatment worldwide. The device employs epidural minimally invasive implantation and wireless power and communication technology, assisting hand grasping in patients aged 18–60 via a pneumatic glove. Clinical trial results showed significant improvement in hand grasping ability and quality of life.

telegram · zaihuapd · Jul 12, 14:39

**Background**: Brain-computer interfaces (BCIs) enable direct communication between the brain and external devices. Invasive BCIs, which require surgical implantation, typically offer higher signal fidelity than non-invasive ones. The approved system is implanted epidurally (on the dura mater) to minimize brain tissue damage, and uses wireless power transfer to eliminate transcutaneous wires, reducing infection risk.

## [Study Finds Claude Code Uses 33k Overhead Tokens vs OpenCode's 7k](https://systima.ai/blog/claude-code-vs-opencode-token-overhead) ⭐️ 8.0/10

A systematic study comparing Claude Code and OpenCode found that Claude Code sends approximately 33,000 tokens of overhead before reading the user's prompt, while OpenCode only sends about 7,000 tokens, indicating a 4.7x difference in harness token inefficiency. This difference directly impacts users' costs when using AI coding assistants, as tokens translate to API charges. The finding raises concerns about design choices that prioritize revenue over efficiency, especially for heavy users. The study captured all requests between the tools and Anthropic's endpoint using a logging proxy, recording exact JSON payloads including system blocks, tool schemas, and messages. One caveat is that the study did not compare the quality of outputs, only token overhead.

hackernews · systima · Jul 12, 18:25 · [Discussion](https://news.ycombinator.com/item?id=48883275)

**Background**: AI coding tools like Claude Code and OpenCode act as 'harnesses' that orchestrate calls to large language models. They send system prompts, tool definitions, and other overhead tokens with every request to maintain context and capabilities. Token efficiency is crucial because users are billed per token, and excessive overhead can significantly inflate costs.

## [Zer0Fit: MCP Server for Google’s TabFM & TimesFM Models](https://www.reddit.com/r/MachineLearning/comments/1uue8cc/zer0fit_i_took_googles_new_tabfm_timesfm_ml/) ⭐️ 8.0/10

A graduate student released Zer0Fit, an MCP server that wraps Google's TabFM and TimesFM foundation models, enabling zero-shot machine learning tasks like classification, regression, and time-series forecasting entirely on local Nvidia GPUs. This project makes state-of-the-art zero-shot tabular and time-series foundation models accessible through a simple chat interface like Open WebUI, lowering the barrier for non-experts to perform ML tasks without training or tuning models. The MCP server runs both models in a single Docker container, requires about 16GB of VRAM on Nvidia GPUs (CUDA only), and includes a 5-minute TTL for dynamic model loading/unloading to free memory.

reddit · r/MachineLearning · /u/Porespellar · Jul 12, 12:32

**Background**: TabFM and TimesFM are zero-shot foundation models from Google Research for tabular data and time-series forecasting, respectively. The Model Context Protocol (MCP) is an open standard that allows LLMs to interact with external tools and data sources. Zer0Fit implements an MCP server that bridges these Google models with LLM interfaces like Open WebUI, enabling chat-based ML workflows.

## [xAI Grok CLI Uploads Entire Codebase by Default](https://gist.github.com/cereblab/dc9a40bc26120f4540e4e09b75ffb547) ⭐️ 8.0/10

Security researchers discovered that xAI's Grok CLI (version 0.2.93) by default uploads the entire codebase and sensitive files like .env to xAI servers, both embedded in model requests and as a git bundle. This poses a serious privacy and security risk for developers, as proprietary code and credentials could be exposed without their knowledge, undermining trust in xAI's data handling. Upload occurs even when the 'improve model' toggle is disabled, and the server still reports upload as enabled; in tests, over 5 GiB from a 12 GB repository was uploaded without rejection.

telegram · zaihuapd · Jul 12, 04:19

**Background**: A CLI (Command Line Interface) is a text-based tool for interacting with software; git bundle packages an entire git repository into a single file, making code transfer easy. This explains why uploading a git bundle equals sending the full codebase.
