## [GPT-5.6 一小时攻克五十年图论猜想](https://www.qbitai.com/2026/07/447873.html) ⭐️ 10.0/10

OpenAI 的 GPT-5.6 Sol Ultra 模型通过协调 64 个子 agent，在不到一小时内证明了存在 50 年的循环双覆盖猜想。OpenAI 还公开了用于此成就的完整提示词（约 700 字符）。 这标志着 AI 系统首次自主解决一个长期未解的数学猜想，展现了高级推理和多智能体协作能力。这可能彻底改变数学研究的方式，并为 AI 在科学发现中的作用树立新标杆。 该模型将问题转化为有限域上的边标号和线性方程组求解，生成了 3 页 PDF 证明。公开的提示词不规定固定步骤，而是定义了验收标准、定义、边界条件和失败情形，并要求动态分配子 agent 和独立审查。

telegram · zaihuapd · 7月12日 03:49

**背景**: 循环双覆盖猜想由 Szekeres（1973）和 Seymour（1979）独立提出，询问是否每个无桥图都存在一组圈，使得每条边恰好被覆盖两次。无桥图是指移除任意一条边都不会使图断开的图。该猜想是图论中的基本问题，五个十年来一直未能被证明。

## [全球首款侵入式脑机接口医疗器械获批](https://t.me/zaihuapd/42515) ⭐️ 10.0/10

中国国家药监局批准了全球首款侵入式脑机接口医疗器械——由博睿康医疗科技（上海）有限公司开发的植入式脑机接口手部运动功能代偿系统，使其正式进入临床应用，用于四肢瘫患者。 这一批准标志着神经技术领域的里程碑式突破，为颈段脊髓损伤导致手部功能丧失的患者提供了新的康复选择，或将在全球范围内推动侵入式脑机接口医疗器械的研发与应用。 该产品采用硬脑膜外微创植入与无线供能通信技术，通过气动手套辅助 18 至 60 岁患者实现手部抓握功能代偿。临床试验结果显示，受试者的手部抓握能力显著提高，生活质量得到改善。

## [研究发现 Claude Code 额外消耗 33K tokens，OpenCode 仅 7K](https://systima.ai/blog/claude-code-vs-opencode-token-overhead) ⭐️ 8.0/10

一项系统性的对比研究发现，Claude Code 在读取用户提示前会额外发送约 33,000 个 tokens，而 OpenCode 仅发送约 7,000 个 tokens，显示前者的 harness token 效率低约 4.7 倍。 这种差异直接影响用户使用 AI 编程助手的成本，因为 tokens 直接对应 API 费用。该发现引发了对设计选择是否优先考虑收入而非效率的担忧，尤其是对于重度用户。 该研究通过日志代理捕获了工具与 Anthropic 端点之间的所有请求，记录了包括系统块、工具架构和消息在内的精确 JSON 负载。一个局限是研究仅比较了 token 开销，未对比输出质量。

hackernews · systima · 7月12日 18:25 · [社区讨论](https://news.ycombinator.com/item?id=48883275)

**背景**: 像 Claude Code 和 OpenCode 这样的 AI 编程工具充当‘harness’，负责编排对大语言模型的调用。它们会在每次请求中发送系统提示、工具定义等额外 tokens，以维护上下文和能力。Token 效率至关重要，因为用户按 token 付费，过多的开销会显著增加成本。

## [Zer0Fit：为谷歌 TabFM 与 TimesFM 模型打造的 MCP 服务器](https://www.reddit.com/r/MachineLearning/comments/1uue8cc/zer0fit_i_took_googles_new_tabfm_timesfm_ml/) ⭐️ 8.0/10

一位研究生发布了 Zer0Fit，这是一个封装了谷歌 TabFM 和 TimesFM 基础模型的 MCP 服务器，使得在本地 Nvidia GPU 上即可完成零样本机器学习任务，如分类、回归和时间序列预测。 该项目通过 Open WebUI 等简单聊天界面，让最先进的零样本表格和时间序列基础模型变得易于使用，降低了非专家执行机器学习任务的门槛，无需训练或调优模型。 该 MCP 服务器在单个 Docker 容器中运行两个模型，需要约 16GB 的 Nvidia GPU 显存（仅支持 CUDA），并设置了 5 分钟的 TTL 以动态加载/卸载模型，从而释放显存。

reddit · r/MachineLearning · /u/Porespellar · 7月12日 12:32

**背景**: TabFM 和 TimesFM 是谷歌研究团队开发的零样本基础模型，分别用于处理表格数据和时间序列预测。模型上下文协议（MCP）是一个开放标准，允许大语言模型与外部工具和数据源交互。Zer0Fit 实现了一个 MCP 服务器，将这些谷歌模型与 Open WebUI 等 LLM 界面桥接，支持基于聊天的机器学习工作流。

## [xAI Grok CLI 默认上传整个代码库](https://gist.github.com/cereblab/dc9a40bc26120f4540e4e09b75ffb547) ⭐️ 8.0/10

安全研究人员发现 xAI 的 Grok CLI（0.2.93 版本）默认将整个代码库及 .env 等敏感文件上传至 xAI 服务器，方式包括嵌入模型请求和打包为 git bundle。 这给开发者带来严重的隐私和安全风险，可能导致专有代码和凭证在不知情的情况下泄露，损害对 xAI 数据处理方式的信任。 即使关闭设置中的“改进模型”开关，上传仍会发生，且服务器端返回上传已启用的状态；在 12 GB 仓库测试中，超过 5 GiB 数据成功上传且未被拒绝。

telegram · zaihuapd · 7月12日 04:19

**背景**: CLI（命令行界面）是一种基于文本的软件交互工具；git bundle 将整个 git 仓库打包成单个文件，方便代码传输。这解释了上传 git bundle 等同于发送完整代码库。
